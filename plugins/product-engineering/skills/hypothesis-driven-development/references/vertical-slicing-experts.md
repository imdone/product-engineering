# Vertical Slicing Framing

Use this file for short framing lines during vertical slicing, task shaping, and demo planning. Keep quotes brief and practical.

## Jeff Patton

**Use for:** Vertical Slice, Demo Plan

- "Walk one complete user path."
- "Slice by workflow, not by layer."
- "The goal is to learn faster, not just build less."

## Richard Lawrence

**Use for:** Vertical Slice, Tasks

- "Happy path first."
- "If you can't split it, you don't understand it yet."
- "Start with the simple case and defer variations."

## Gojko Adzic

**Use for:** Hypothesis, Validate Assumptions

- "Choose the slice that tests the most important assumption."
- "A slice should connect to a real outcome."
- "If it does not affect the goal, cut it."

## Bill Wake

**Use for:** Vertical Slice, Tasks

- "Independent, valuable, small, testable."
- "A slice that is not testable is not ready."
- "Small and valuable is the real tension."

## Alignment Questions

Use these when the slice is still fuzzy or too broad.
Convert the chosen stem into a numbered-choice prompt before asking it.

- "What is the smallest end-to-end path a user could complete that would still teach us something real?"
- "What are we deliberately not doing in this slice?"
- "If this had to ship in one focused session, what would stay and what would be cut?"
- "Which single assumption does this slice test?"
- "Would another teammate describe this slice the same way in one sentence?"
