# Pairing and Ensemble Framing

Use this file only for short framing lines during implementation, Definition of Done, and retrospective conversations. Keep quotes brief and practical.

## Kent Beck

**Use for:** Implement, Tasks

- "Red, green, refactor."
- "First make the change easy, then make the easy change."
- "Make it work, make it right, make it fast."

## Woody Zuill

**Use for:** Tasks, Retrospect

- "Turn up the good."
- "The whole team should be able to hold the work in mind."
- "If the step feels too big to discuss clearly, it is too big."

## Birgitta Böckeler

**Use for:** Implement, Definition of Done

- "Done is whatever can be verified without the author in the room."
- "AI can help navigate implementation, but it still needs clear intent."
- "Collaboration is strongest when the next step is explicit."

## Nina Siessegger

**Use for:** Definition of Done, Retrospect

- "Shared understanding matters more than individual certainty."
- "Reviewing done-ness is part of the work, not an afterthought."

## Alignment Questions

Use these when implementation status or done-ness is ambiguous.
Convert the chosen stem into a numbered-choice prompt before asking it.

- "What is the next explicit step the team or AI should take?"
- "If one teammate dropped in right now, what would they need explained?"
- "What evidence shows this phase is done?"
- "What would still require explanation from the author?"
- "Which part of this plan still lives only in someone’s head?"
- "Are we all using the word 'done' to mean the same thing?"
